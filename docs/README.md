# Documentation

The [user guides](user-guide/README.md) explain how to use Guitar Vault in **English** and **French**. They are also published inside the app at `/help`, under **Help & guides / Aide et guides**, including a FAQ.

Edit the Markdown files in `user-guide/en/` and `user-guide/fr/`. The website renders these same files; there is no separate copy of the guide text in templates or the database.

## Beta testing

Use the [three-role beta kit](beta/README.md) for an owner, buyer and luthier session: English/French task cards, synthetic uploads, facilitator checks and a blank observation sheet. [Automated results](beta/automated-results.md) are recorded separately from human observations.
