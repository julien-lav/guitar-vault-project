# Documents, libellés et archives

Conservez vos factures et certificats, organisez votre bibliothèque et choisissez les fichiers qui accompagnent un transfert.

## Ajouter et retrouver un document

1. Ouvrez un instrument qui vous appartient puis **Documents de l’instrument**.
2. Saisissez un titre et une catégorie, sélectionnez un PDF, JPEG ou PNG de 5 Mo maximum, puis envoyez le document.
3. Ouvrez **Mon espace → Mes documents** pour retrouver les fichiers ajoutés, reçus lors d’un transfert accepté ou accessibles comme pièces de rapports.
4. Recherchez un titre ou nom de fichier. Combinez les filtres instrument, catégorie, accès et vue de bibliothèque, puis appliquez-les. Réinitialisez les filtres pour recommencer.

La limite est de 20 fichiers ajoutés par contributeur et instrument, pièces de rapports comprises. Ajouter un fichier ne le partage pas automatiquement. Le téléchargement fournit le fichier d’origine.

## Modifier vos libellés personnels

Choisissez **Gérer** près du fichier. Modifiez le titre ou la catégorie puis enregistrez vos libellés. Ces libellés sont personnels : le fichier, les rapports et les transferts conservent les informations d’origine. Les autres lecteurs gardent leurs propres libellés.

## Archiver et restaurer

Archivez le document depuis sa page de gestion. Il disparaît de votre bibliothèque active et de vos nouvelles sélections de transfert. Les téléchargements, rapports et propositions existants restent disponibles ; les autres lecteurs ne sont pas affectés.

Pour le retrouver, ouvrez **Mes documents**, choisissez **Documents archivés** ou **Tous les documents**, puis appliquez les filtres. Ouvrez **Gérer** et restaurez le document dans votre bibliothèque. L’archivage ne libère pas de place dans le quota.

## Supprimer un fichier inutilisé

Seul le contributeur peut supprimer un fichier qui n’a jamais été joint à un rapport ou sélectionné pour un transfert et pour lequel aucun accès n’a déjà été accordé. S’il est éligible, la page de gestion propose de supprimer ce fichier inutilisé. Relisez la page de confirmation puis confirmez sa suppression définitive uniquement si vous souhaitez le retirer pour de bon. La suppression libère une place dans le quota.

Un fichier référencé dans un rapport ou un transfert est conservé, même si le transfert est refusé ou annulé. Archivez-le pour ranger votre bibliothèque. Si la page indique que l’entrée a changé, rouvrez-la avant de réessayer.

## Comprendre les niveaux d’accès

- **Privé** : accessible au contributeur.
- **Référencé dans un transfert** : inclus dans une proposition enregistrée. Ce libellé ne signifie pas, à lui seul, que le destinataire a accepté ou obtenu l’accès.
- **Participants de la demande** : pièce partagée avec le contributeur et le demandeur d’origine.
- **Lecteurs du rapport** : pièce partagée avec le contributeur, le demandeur d’origine et le propriétaire actuel de l’instrument.

Pour les choix exacts, consultez les guides [transferts de propriété](transfers.md) et [rapports de luthier](luthiers.md).
